### **5.1 Markdown Formatter**
- Converts raw content into:
  - Clean Markdown
  - Docusaurus callouts (`:::note`, `:::tip`, `:::warning`)
- Maintains heading hierarchy + table integrity.
- Adds frontmatter automatically.

### **5.2 Code Block Enhancer**
- Adds syntax highlighting with language tags.
- Ensures fenced code blocks are properly closed.

### **5.3 Component Injector**
- Automatically inserts:
  - `<PersonalizeButton />`
  - `<UrduTranslateButton />`
  - `<ActionButtons />`
- Context-aware placement (e.g., top of every module page).
