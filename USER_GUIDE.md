# User Guide: Authentication Redirect & Urdu Translation

## Overview
This guide explains how to use the new authentication redirect and Urdu translation features in the Humanoid Robotics Textbook platform.

## Authentication Redirect Feature

### After Sign In
When you sign in to the platform, you will be automatically redirected to the module page instead of the home page. The system remembers the last module you accessed and redirects you there for a seamless learning experience.

### New Users
If you are a new user, you will be redirected to the Introduction module to start your learning journey.

### Returning Users
If you have previously accessed a module, you will be redirected back to that module to continue where you left off.

## Urdu Translation Feature

### How to Translate Content
1. Navigate to any module page
2. Look for the "Translate to Urdu" button (appears as 🇵🇰 flag)
3. Click the button to translate the current content to Urdu
4. The content will be translated while preserving formatting (headings, paragraphs, lists, etc.)

### Toggle Between Languages
- After translating to Urdu, the button will change to "Translate to English" (appears as 🇬🇧 flag)
- Click this button to switch back to the original English content
- Your language preference is saved automatically for each module

### Translation Quality
- Translations are generated using AI technology
- Technical terms are preserved as much as possible
- Translation quality may vary for highly specialized robotics concepts
- The original English content is always available for reference

### Error Handling
- If translation fails, an error message will appear
- The original content remains visible
- You can try translating again by clicking the button

## Performance and Caching
- Translated content is cached for 24 hours
- Subsequent visits to the same translated content will load faster
- Cached translations are automatically refreshed after 24 hours

## Troubleshooting

### Translation is taking too long
- Translation requests have a 30-second timeout
- If you see a timeout error, try again later
- Complex content may take longer to translate

### Translation button is disabled
- Ensure you are signed in to your account
- The button may be disabled if the system is processing a previous request

### Content formatting issues
- The system preserves most formatting during translation
- If you notice formatting problems, try toggling the language or refreshing the page

## Privacy and Data
- Your translation preferences are stored locally in your browser
- Translation requests are processed securely
- No personal data is shared during the translation process
